# PRD：機器狗強化學習訓練模擬器（v1）

> 狀態：草稿 ｜ 日期：2026-11-05 ｜ 範圍：只在模擬中學習與研究（不做實體部署）

## 1. 問題陳述

想學習用強化學習（RL）讓四足機器狗學會走路、跌倒站起、避障，但目前沒有一套能在自己電腦（RTX 5060，8GB VRAM）上順利跑起來的訓練環境。現成框架（Isaac Lab、MuJoCo Playground、legged_gym 等）功能強但安裝門檻高、範例分散，而且多半假設 16GB 以上的顯示卡。如果不解決，就只能停在看論文、看影片，沒辦法實際調 reward、看訓練曲線，也就累積不了 RL 的實作經驗。

## 2. 目標

1. **能在 RTX 5060 上訓練**：平地行走策略在 **60 分鐘內**收斂（速度追蹤誤差 < 0.15 m/s）。
2. **三種技能都能訓練並播放**：行走、跌倒後站起、導航避障，各有可重現的訓練設定。
3. **方便做實驗**：改 reward 權重、地形或機器人參數只要修改設定檔，不必改程式碼；一次實驗從修改到看到結果 < 5 分鐘（不含訓練時間）。
4. **可換機器人**：換一隻四足機器狗（新的 URDF/MJCF）只需要提供模型檔和一份設定檔。

## 3. 非目標（v1 不做）

| 不做 | 原因 |
|---|---|
| Sim-to-real 部署到實體機器人 | 已確定只在模擬中研究；domain randomization 只做到基本程度 |
| 自己寫物理引擎 | 工作量極大，而且精度比不上 MuJoCo/PhysX，直接用現成引擎 |
| 相機影像（視覺）輸入 | 視覺 RL 很吃 VRAM，8GB 會撐不住；導航改用 raycast／高度圖代替 |
| 樓梯、碎石等崎嶇地形 | 第一階段沒選；地形系統會預留介面（列在 P2） |
| 多機器人協作、圖形化編輯器 | 和核心問題無關，屬於額外加分 |

## 4. 使用者故事

**主要使用者：RL 學習者／研究者（你自己）**
- 我想用一行指令開始訓練行走策略，這樣就不用花時間處理環境設定。
- 我想即時看到 reward 曲線和各項 reward 的分項數值，這樣才知道是哪一項 reward 造成機器狗出現奇怪的步態。
- 我想打開 3D 視窗播放訓練好的策略，並用鍵盤或搖桿下速度指令，這樣能直接看它走得好不好。
- 我想從中斷的 checkpoint 接續訓練，這樣當機或關機時不會白跑。
- 我想讓同一份設定在固定 seed 下得到相近的結果，這樣比較不同實驗才有意義。

**次要使用者：之後加入的同學或社員**
- 我想照著 README 在 30 分鐘內跑起第一個範例，這樣不用先懂全部程式碼。

**邊界情況**
- VRAM 不夠時，我希望程式給出明確提示（例如「請把 num_envs 調到 2048」），而不是直接當掉。
- 訓練發散（出現 NaN）時，我希望程式自動停止並保留最後一個正常的 checkpoint。

## 5. 需求

### P0：必須有

| # | 需求 | 驗收標準 |
|---|---|---|
| P0-1 | **GPU 平行模擬**：同時跑數千個環境 | 在 RTX 5060 上跑 ≥ 2048 個環境，VRAM < 7GB，吞吐量 ≥ 50k steps/s |
| P0-2 | **預設機器狗模型**：~~Unitree Go2~~ → 改用 Unitree Go1（實作時決定：MuJoCo Playground 已有調好、適合 GPU 平行模擬的 Go1 模型；Go2 移到 P2） | 載入後能站穩 10 秒不倒 |
| P0-3 | **行走任務**：依 (vx, vy, ωz) 速度指令行走 | 收斂後平均速度誤差 < 0.15 m/s，20 秒內跌倒率 < 5% |
| P0-4 | **跌倒站起任務**：從隨機倒地姿態恢復站立 | 5 秒內站起的成功率 ≥ 85% |
| P0-5 | **PPO 訓練流程**：checkpoint、接續訓練、固定 seed | 中斷後能接續；同一 seed 跑 3 次，最終 reward 差距 < 10% |
| P0-6 | **設定檔驅動**：reward 權重、指令範圍、環境數量都寫在 YAML | 修改權重不需要改 Python 程式碼 |
| P0-7 | **監控**：TensorBoard 或 W&B 記錄總 reward 和各分項 reward | 每個 reward 分項都有自己的曲線 |
| P0-8 | **播放模式**：載入策略、3D 顯示、用鍵盤下速度指令 | 能錄成 mp4 |

### P1：最好有

| # | 需求 | 驗收標準 |
|---|---|---|
| P1-1 | **導航避障任務**：隨機障礙物，用 raycast 或高度圖觀測，走到目標點 | 10×10 m 場地、5 個障礙物時，抵達率 ≥ 80% |
| P1-2 | **基本 domain randomization**：摩擦力、質量、外力推擠 | 各項開關都可以在設定檔切換 |
| P1-3 | **課程學習**：指令速度範圍隨表現逐步放寬 | 可以在曲線上看到範圍擴大 |
| P1-4 | **VRAM 偵測與建議** | 不夠時給出建議的 num_envs，不會直接 OOM |

### P2：未來考量（現在不做，但架構要預留）

- 崎嶇地形（樓梯、斜坡、碎石）：地形產生器做成可替換的模組
- 自訂機器狗：機器人參數（關節、PD 增益、初始姿態）全部放在獨立設定檔
- Sim-to-real：保留 action latency 和觀測雜訊的接口
- 技能切換：用高階策略在行走、站起、導航之間切換

## 6. 成功指標

**領先指標（第 1～2 週就看得到）**
- 從全新環境到跑完第一次訓練：< 1 天
- 行走策略訓練時間：≤ 60 分鐘（目標 30 分鐘）
- 單次實驗迭代（改設定、重訓、看結果）：可以一天跑 ≥ 5 次

**落後指標（1～3 個月）**
- 三種技能全部達到 P0/P1 的驗收標準
- 累積 ≥ 20 組有紀錄的 reward 設計實驗，並寫下心得
- 換第二隻機器狗模型時，只需修改 1 份設定檔
